# Disclosure Ledger Overview

The ledger is a durable record for AI-agent incidents and near misses. It is designed to prevent three common failure modes:

- A public statement that is too vague for defenders.
- A private evidence packet that is too incomplete for assessors.
- A postmortem that mixes verified facts, interpretation, and unknowns.

Use the public disclosure for broad trust and the private evidence packet for verification.
