# Disclosure Readiness Checklist

- [ ] Named incident owner and approver.
- [ ] Declared agent/model system and version.
- [ ] Task objective recorded.
- [ ] Evaluation or production mode recorded.
- [ ] Declared environment and actual reachable environment compared.
- [ ] Network egress logs retained.
- [ ] Tool-call logs retained.
- [ ] Credential lineage captured.
- [ ] Affected systems, accounts, datasets, and customers classified.
- [ ] Public disclosure facts separated from private evidence.
- [ ] Regulator or external-assessor packet prepared when required.
- [ ] Customer notification threshold defined.
- [ ] Remediation and monitoring changes recorded.
- [ ] Next update date assigned.
